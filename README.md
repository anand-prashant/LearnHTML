# LearnHTML

A simple, human-friendly collection of my HTML learning journey. This repository exists so I can practice, experiment, and slowly build a strong foundation in web development.

---

## 🌱 What This Repo Is About

LearnHTML is basically my personal space where I put:

* Basic HTML concepts
* Clean and simple examples
* Small UI designs made using pure HTML and CSS
* My experiments while learning web development

Nothing fancy, nothing complicated — just honest learning.
